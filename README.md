## What is CELLO?

CELLO is an open source alternative to proprietary LLM code quality leaderboards (like SonarSource's). It evaluates **both open source and closed source** LLMs on real open source projects, providing transparent and reproducible benchmarks.

### Key Differences from SonarSource

| Feature | CELLO | SonarSource |
|---------|-------|-------------|
| Open Source Models | ✅ 6 models | ❌ Limited |
| Test Cases | ~12,800+ | ~4,000 |
| Real Project Evaluation | ✅ 4 real OSS projects | ❌ Synthetic |
| Transparent Methodology | ✅ Fully open | Partially |
| Community Contributions | ✅ Open for PRs | ❌ Closed |
| License | Apache 2.0 | Proprietary |

## Metrics

- **Bug Detection** — Static analysis for bugs and logic errors
- **Vulnerability Detection** — Security-focused SAST scanning
- **Code Smell Detection** — Anti-patterns and style violations
- **Complexity Score** — Cyclomatic and cognitive complexity
- **Maintainability Score** — Documentation, naming, structure

## Deploy to GitHub Pages

### Option 1: Direct deployment

1. Fork or clone this repository
2. Go to **Settings → Pages**
3. Set source to **Deploy from a branch**
4. Select `main` branch, `/ (root)` folder
5. Click **Save**

Your site will be live at `https://<username>.github.io/<repo-name>/`

### Option 2: Quick manual deploy

```bash
# Clone and push to your own repo
git clone https://github.com/cello-benchmark/cello.git
cd cello
git remote set-url origin https://github.com/<your-username>/<your-repo>.git
git push -u origin main
```

Then enable GitHub Pages in Settings.

### Option 3: Local preview

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx serve .
```

Open `http://localhost:8000` in your browser.
