## What is CELLO?

CELLO is an open source benchmark for evaluating LLM code transpilation quality. It evaluates **C → Rust** transpilation using **real rustc compilation** and scores across 6 quality dimensions.

### Key Features

| Feature | CELLO |
|---------|-------|
| Real Compilation | ✅ Uses rustc to verify generated code |
| Transparent Methodology | ✅ Fully open — all prompts, configs, and scripts public |
| Detailed Reports | ✅ C source, Rust output, errors, and scoring breakdowns |
| Reproducible | ✅ All evaluation code available |
| Community Contributions | ✅ Open for PRs |
| License | Apache 2.0 |

| Project | C Code Size | Description |
|---------|-------------|-------------|
| string_utils | 1,768 bytes | String utilities (duplicate, trim, lowercase, concat, count) |
| buffer | 1,997 bytes | Dynamic buffer with growing byte array |
| hashmap | 3,297 bytes | Hash map with separate chaining |

## Evaluation Dimensions

1. **Compilation (25%)** — Does it compile with rustc?
2. **Safety (20%)** — Memory safety improvements (unsafe blocks, error handling)
3. **Quality (20%)** — Idiomatic Rust patterns, documentation, naming
4. **Correctness (15%)** — Functional equivalence, edge cases, tests
5. **Maintainability (10%)** — Code organization, public API clarity
6. **Performance (10%)** — Efficiency patterns (minimal cloning, references)

## Deploy to GitHub Pages

### Option 1: Direct deployment

1. Fork or clone this repository
2. Go to **Settings → Pages**
3. Set source to **Deploy from a branch**
4. Select `main` branch, `/ (root)` folder
5. Click **Save**

Your site will be live at `https://<username>.github.io/<repo-name>/`

### Option 2: Quick manual deploy

```bash
# Clone and push to your own repo
git clone https://github.com/cello-benchmark/cello.git
cd cello
git remote set-url origin https://github.com/<your-username>/<your-repo>.git
git push -u origin main
```

Then enable GitHub Pages in Settings.

### Option 3: Local preview

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx serve .
```

Open `http://localhost:8000` in your browser.

- Generated Rust code from each model
- Full rustc compilation output (including errors)
- Detailed scoring breakdown across all 6 dimensions
- Side-by-side model comparison
